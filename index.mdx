# TaskBoard Demo

TaskBoard Demoは、Mintlifyを使ったドキュメント生成を試すための、小規模なタスク管理Webアプリです。

<Info>
  HTML、CSS、JavaScriptだけで動作します。バックエンド、外部データベース、ユーザー登録は不要です。
</Info>

## 技術スタック

| 項目 | 技術 |
| --- | --- |
| 画面 | HTML5 + CSS |
| ロジック | JavaScript（ES Modules） |
| 永続化 | ブラウザの `localStorage` |
| テスト | Node.jsの組み込みテストランナー |
| サーバーAPI | なし |
