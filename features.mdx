# 機能仕様

## タスクを追加する

「New task...」にタイトルを入力し、「Add task」を選択します。

- 前後の空白は除去します。
- 空白だけのタイトルは登録できません。
- 追加時の状態は `active` です。
- IDは `crypto.randomUUID()` で生成されます。
- 作成日時はISO 8601形式で保存されます。

## タスクを編集する

各タスクの「Edit」を選択すると、ブラウザの `prompt()` ダイアログが開きます。

- キャンセルした場合は変更しません。
- 空白だけの入力は変更しません。
- 編集可能なのはタイトルです。

## 完了・未完了を切り替える

タスクのチェックボックスによって状態を `active` と `done` の間で切り替えます。完了したタスクのタイトルには取り消し線が表示されます。

## 削除する

「Delete」を選択すると、対象タスクを一覧から削除します。確認ダイアログはありません。

<Warning>
  削除操作の取り消し機能はありません。
</Warning>

## 検索・フィルター

- 検索はタイトルの部分一致で、大文字・小文字を区別しません。
- 状態フィルターは「All tasks」「Active」「Completed」の3種類です。
- 検索条件と状態フィルターは同時に適用されます。
- 一致するタスクがない場合は「No tasks found.」と表示します。
- 未完了件数は、検索やフィルターで絞り込まれていない全タスクから集計されます。

## 保存

追加・編集・完了切替・削除の後、タスク一覧全体を `localStorage` に保存します。検索文字列とフィルターの選択は保存されません。
